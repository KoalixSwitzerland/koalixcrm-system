# REQ-0037: Das System erhält Sicherheitsupdates als Dependabot-Pull-Requests gegen den Standard-Branch

## Lizenzseite
Open-Source-Backend (`/app/koalixcrm`, Repository-Einstellung und Konfigurationsdatei)

## Quelle
Entscheidung des Product Owners 2026-10-25 (Dependabot-Sicherheitsupdates bleiben aktiv);
ORG-BE-ADR-0015 §8; ADR-0022.

## Why
Das Gate meldet Schwachstellen, behebt sie aber nicht. Dependabot-Sicherheitsupdates zielen immer auf den
Standard-Branch des Repositories; nur mit `develop` als Standard-Branch (REQ-0036) landen Fixes auf dem
Integrations-Branch statt auf `main`.

## Beschreibung
Dependabot-Sicherheitsupdates sind für das pip-Ökosystem aktiviert und erzeugen Pull Requests gegen den
Standard-Branch `develop`. Die Konfigurationsdatei enthält für diese Updates keine `target-branch`-Angabe.
Jeder Dependabot-Pull-Request durchläuft den Merge-Job (REQ-0029) und wird nach Review gemergt, nie
automatisch. Das Ökosystem `github-actions` hält den Pin des zentralen Scans aktuell (REQ-0032). Die
Anforderungsdateien bleiben einfache Zeilen mit Anforderungen, damit Dependabot sie unabhängig vom
Dateinamen erkennt.

## Acceptance Criteria

### AC-1: Aktivierung
- [ ] Die Repository-Einstellung "Dependabot security updates" ist aktiv.
- [ ] Die Datei `.github/dependabot.yml` deklariert das Ökosystem `pip` für das Verzeichnis `/` (liest `setup.py`).
- [ ] Die Datei `.github/dependabot.yml` deklariert das Ökosystem `pip` für das Verzeichnis `/docker/requirements`.
- [ ] Die Datei `.github/dependabot.yml` deklariert das Ökosystem `github-actions` für das Verzeichnis `/`.
- [ ] Jede Datei in `docker/requirements/` besteht aus einfachen Anforderungszeilen.
- [ ] Die Datei `.github/dependabot.yml` setzt für ihre Ökosysteme ein wöchentliches Intervall.

### AC-2: Zielbranch
- [ ] Die Datei `.github/dependabot.yml` enthält keine `target-branch`-Angabe, auf die sich Sicherheitsupdates stützen.
- [ ] Dependabot-Sicherheitsupdates eröffnen Pull Requests gegen den Standard-Branch `develop`.

### AC-3: Gate und Merge
- [ ] Jeder Dependabot-Pull-Request löst den Merge-Job aus REQ-0029 aus.
- [ ] Kein Workflow und keine Repository-Einstellung merged einen Dependabot-Pull-Request automatisch.
- [ ] Ein Dependabot-Pull-Request wird erst nach Review und grünem Merge-Job gemergt.

## Quality Attributes
- **Security**: Fixes erreichen `main` ausschließlich über den regulären Release.

## Affected Components
- Backend: `.github/dependabot.yml`, `docker/requirements/*.txt`
- Frontend: keine
- Deployment: GitHub-Repository-Einstellungen

## Not in Scope of this Requirement
- Dependabot-Versionsupdates für nicht sicherheitsrelevante Aktualisierungen von Python-Paketen.
- Automatisches Mergen von Dependabot-Pull-Requests.
- Die vorhandenen Branches `dependabot/pip/*`: Sie basieren auf dem bisherigen Standard-Branch `main`; ihre Behandlung ist ein Migrationsposten der Umstellung nach REQ-0036.

## Dependencies
- REQ-0029 (Merge-Job), REQ-0032 (Pin-Aktualisierung), REQ-0036 (Standard-Branch)
- ORG-BE-ADR-0015 §8, ADR-0022
